The Problem

Florida compliance should not live in spreadsheets.

Florida Statute 538 requires strict recordkeeping: seller ID verification, fingerprints, signatures, item records, minimum 15-day holds, and daily purchase reports for law enforcement. SDMS keeps those requirements inside the workflow so staff can operate faster with less compliance risk.

What I Built

Compliance enforcement at the data layer, not just the UI.

  • lockServer-side 15-day hold enforcement rejects sold status before an item clears.
  • historyImmutable audit log records every write operation before returning.
  • no_deleteNo hard deletes on compliance-relevant tables.
  • badgeCustom JWT auth with bcrypt and role-based access for Owner, Manager, Employee, and Auditor.
  • printReceipt printing and configurable inventory label printing for Dymo/Zebra-style label sizes.

Technical Highlights

  • apiPython 3 / FastAPI backend.
  • webReact 18 / TypeScript / Vite / Tailwind frontend.
  • databasePostgreSQL on Neon, deployed with Render + Netlify.
  • desktop_windowsWindows desktop installer from the same codebase using PyInstaller, Nginx, bundled PostgreSQL, and Inno Setup.
  • monitoringLive precious metals pricing via Yahoo Finance futures with Decimal-based melt calculations.
