# Roadmap

## High Priority

- Define the event gallery model: public previews, private login, free downloads, paid purchases, or hybrid access.
- Choose the gallery/e-commerce implementation path for Netlify hosting.
- Replace generated placeholder imagery with final portfolio photography when available.
- Add real contact email or booking workflow copy if desired.
- Add SEO metadata per page, including Open Graph images.
- Add a privacy page if collecting inquiries through Netlify Forms.

## Medium Priority

- Expand the new Events page into a dedicated Gallery system with individual event gallery pages.
- Add user login or gated event access for private post-fight galleries.
- Add purchase/download workflow once pricing direction is decided.
- Add individual project/case-study pages.
- Add filter controls to the combat and architecture galleries.
- Add image delivery optimization only if it preserves original source quality, such as lossless optimization, responsive source sets generated from approved masters, or a dedicated image CDN.
- Add a custom 404 page.

## Nice To Have

- Add testimonials or client logos once approved.
- Add behind-the-scenes/process images.
- Add schema.org structured data for a local professional photography business.
