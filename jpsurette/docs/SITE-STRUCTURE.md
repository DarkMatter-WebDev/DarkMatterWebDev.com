# Site Structure

## Pages

- `index.html` - home overview with split combat and architecture entry points plus selected work.
- `combat.html` - combat sports portfolio and service positioning.
- `events.html` - post-event gallery/archive direction for fight nights and event drops.
- `architecture.html` - architecture and real estate portfolio and service positioning.
- `everything-else.html` - broader photography services such as estate services, professional portraits, commercial work, editorial, products, and select private events.
- `about.html` - Jonathan Peter Surette bio, philosophy, and process.
- `contact.html` - project inquiry form wired for Netlify Forms.

## Shared Files

- `styles.css` - global layout, typography, navigation, galleries, forms, and responsive rules.
- `script.js` - cursor effect, mobile navigation, reveal animation, and contact submit state.
- `netlify.toml` - Netlify publish settings, cache headers, and fallback redirect.
- `assets/logo.svg` - local wordmark.
- `assets/*.png` - generated local imagery used by the site.

## Navigation

Top navigation links to separate pages, not section anchors. The active page gets `is-active` on its navigation link.
