# JPS Surette Website Notes

This folder is the project memory for the JPS Surette Photography website.

Use it to keep decisions, structure, change history, and future implementation ideas in one readable place. When the site changes, update `CHANGELOG.md`; when a future idea appears, add it to `ROADMAP.md`; when structure shifts, update `SITE-STRUCTURE.md`.

## Files

- `PROJECT-BRIEF.md` - business, audience, brand, and content direction.
- `SITE-STRUCTURE.md` - current page map and file structure.
- `CHANGELOG.md` - dated record of meaningful changes.
- `ROADMAP.md` - future improvements and open items.
- `CONTENT-INVENTORY.md` - reusable copy, assets, and source notes.
