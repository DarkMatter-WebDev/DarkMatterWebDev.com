ABOUT THE SITE

A mobile-first marketing page that doubles as the app’s front door.

MetalsCalc.com is a single-page product site built to explain, promote, and install a PWA precious-metal buying calculator. The headline says it all: One list for everything. Fully customizable.

The page leads with live Au/Ag/Pt spot prices above the fold — proving the product is real and pulling data before a visitor even scrolls. From there, four feature sections walk through the core workflows: list mode, custom purity settings, invoicing, and the My Value margin tool.

Visitors on a phone can install the PWA directly from the site with a single “Add to Home Screen” step. Desktop visitors get the full feature overview and can open the app in their browser without installing anything.

The design is intentionally lean — one strong headline, a live price row, and feature sections that explain the product and close the install without friction.
