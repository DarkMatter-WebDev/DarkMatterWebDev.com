# Feature: Custom Business Web Apps

Last updated: 2026-06-01

## Summary

Custom Business Web Apps are positioned as private online tools built into or alongside a client's website. They can let owners, staff, and customers log in and perform business workflows.

## Current Site Messaging

- Owner, staff, and customer logins.
- Customer records, dashboards, and reports.
- Online stores, checkout flows, and payments.
- API connections and automations.
- Role-based access and admin tools.
- Ongoing management and help desk support available.

## Visual Direction

The service page now uses app-like mockups to help business owners imagine practical uses:

- Operations dashboard with metrics and customer rows.
- Automation flow showing connected systems.
- Admin permissions matrix for role-based access.
