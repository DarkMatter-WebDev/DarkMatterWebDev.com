# Feature: Website Care Plans

Last updated: 2026-06-01

## Summary

Website Care Plans position Dark Matter as an ongoing website partner after launch, covering hosting, updates, maintenance, and support.

## Current Plan Direction

- Entry-level care begins at `$79/mo`.
- Higher tiers support more hands-on updates and ongoing management.
- Team Help Desk is a premium tier at `$1,500+/mo`.

## Team Help Desk

Team Help Desk is intended for clients who need support beyond basic website updates, especially when:

- Multiple staff members need help.
- A custom business web app has individual accounts.
- Internal workflows, reports, or admin tools require operational support.
- Customer-facing app users may need assistance.

## Future Notes

Document support scope carefully before selling this tier:

- Supported channels.
- Response time expectations.
- Number of covered users.
- Included monthly support volume.
- Escalation path for bugs, feature requests, and urgent issues.
