# Internationalization (English / Spanish)

Last updated: 2026-06-01

The site ships in two languages. English pages live at the repo root. Spanish pages
are **exact, fully-translated mirrors** under `es/` (and `es/services/`). Layout,
styling, structure, classes, images, and behavior are identical to the English
source — only human-readable text is translated.

Spanish target: **neutral Latin American Spanish** (e.g., "computadora", "ustedes",
never "vosotros"; avoid Spain-only vocabulary).

## File mapping

| English                              | Spanish                                  |
| ------------------------------------ | ---------------------------------------- |
| `index.html`                         | `es/index.html`                          |
| `services.html`                      | `es/services.html`                       |
| `process.html`                       | `es/process.html`                        |
| `casestudies.html`                   | `es/casestudies.html`                    |
| `contact.html`                       | `es/contact.html`                        |
| `built-by.html`                      | `es/built-by.html`                       |
| `services/<name>.html`               | `es/services/<name>.html`                |

Filenames stay identical (so internal relative links keep working inside `es/`).

## Asset path rule (only mechanical change to paths)

Spanish files sit one directory deeper than their English source, so every
**asset** reference (`assets/...`, `../assets/...`) and the `rail.js` script `src`
gains one extra `../`:

- root EN `assets/x` → ES `../assets/x`
- service EN `../assets/x` → ES `../../assets/x`

Internal page links (e.g. `services/website-design.html`, `../process.html`,
`index.html`, `contact.html`, `built-by.html`, `casestudies.html#elite-yacht`) are
**left unchanged** — because the Spanish file is physically inside `es/`, the same
relative links resolve to the matching Spanish page. External URLs (`https://`,
`tel:`, `sms:`, `wa.me`) are unchanged.

## `<html>` lang attribute

English: `<html class="dark" lang="en">` → Spanish: `<html class="dark" lang="es">`
(This is also how `rail.js` knows to use Spanish popover text.)

## Language auto-detect + persistence (head script)

Add as the **first element inside `<head>`** (right after the `<meta>` charset/viewport),
before stylesheets, to avoid a flash.

On every **English** page (replace the URL with this page's Spanish counterpart):

```html
<script>(function(){try{var p=localStorage.getItem('dm_lang');var u="ES_COUNTERPART_URL";if(p==="es"){location.replace(u);return;}if(!p&&(navigator.language||navigator.userLanguage||"").toLowerCase().indexOf("es")===0){location.replace(u);}}catch(e){}})();</script>
```

On every **Spanish** page (replace the URL with this page's English counterpart):

```html
<script>(function(){try{if(localStorage.getItem('dm_lang')==="en"){location.replace("EN_COUNTERPART_URL");}}catch(e){}})();</script>
```

Counterpart URL examples:
- EN `index.html` → `es/index.html`; ES `es/index.html` → `../index.html`
- EN `services/website-design.html` → `../es/services/website-design.html`;
  ES `es/services/website-design.html` → `../../services/website-design.html`

No redirect loop: detection never sets storage, and the Spanish page only bounces
back when storage is explicitly `"en"` (set by the toggle).

## Language toggle (UI)

A small `EN / ES` switch. The current language is a plain highlighted span; the other
language is a link to the counterpart page that records the explicit choice in
`localStorage` via inline `onclick`.

Desktop — insert inside the desktop `<nav>` link row, immediately before the primary
CTA button (Schedule Consultation / Start Project).

English page (EN active):

```html
<div class="lang-switch flex items-center gap-1.5 font-label-mono text-label-mono shrink-0">
<span class="text-electric-cyan" aria-current="true">EN</span>
<span class="text-outline/50">/</span>
<a href="ES_COUNTERPART_URL" hreflang="es" lang="es" aria-label="Cambiar a español" onclick="try{localStorage.setItem('dm_lang','es')}catch(e){}" class="text-on-surface-variant hover:text-electric-cyan transition-colors duration-300">ES</a>
</div>
```

Spanish page (ES active):

```html
<div class="lang-switch flex items-center gap-1.5 font-label-mono text-label-mono shrink-0">
<a href="EN_COUNTERPART_URL" hreflang="en" lang="en" aria-label="Switch to English" onclick="try{localStorage.setItem('dm_lang','en')}catch(e){}" class="text-on-surface-variant hover:text-electric-cyan transition-colors duration-300">EN</a>
<span class="text-outline/50">/</span>
<span class="text-electric-cyan" aria-current="true">ES</span>
</div>
```

Mobile — insert into the mobile top `<header>` flex row (right side). If a hamburger
button exists, wrap the toggle + button together so the toggle sits to its left; the
toggle uses the same markup as above. Keep it compact.

## hreflang alternates (in `<head>`, both languages)

```html
<link rel="alternate" hreflang="en" href="EN_PATH"/>
<link rel="alternate" hreflang="es" href="ES_PATH"/>
<link rel="alternate" hreflang="x-default" href="EN_PATH"/>
```
(Use root-relative paths, e.g. `/index.html` and `/es/index.html`.)
