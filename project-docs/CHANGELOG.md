Verified with instrumented buffer-write counters on real resize events: height-only resizes (812→700 on apps, 700→600 on process) produce **zero** buffer writes on every canvas; a width resize (375→414) resizes exactly once after the debounce to the correct new dimensions; account.html confirmed on the new script + CSS.
